# Ritmo Que Funciona

Create a premium, modern landing page and interactive website for a digital product called:

ROTINA PRODUTIVA

RITMO QUE FUNCIONA

Subtitle:
Um sistema prático para organizar prioridades, proteger o foco e sustentar o que importa.

The website must feel like a direct digital version of the PDF. Use the same visual identity, design philosophy, colours, typography style, spacing, and premium minimalist aesthetic.

🎨 DESIGN & VISUAL STYLE

The design should be:

Extremely clean

Modern and premium

Minimalist

Editorial-style

Professional

Calm and sophisticated

Focused on readability

Similar to a high-end productivity magazine/editorial

Colour Palette

Use a colour palette inspired directly by the PDF:

Warm off-white / cream background

Deep navy / almost black text

Muted beige and light grey sections

Soft neutral tones

Very subtle contrast

Avoid:

Bright colours

Neon colours

Excessive gradients

Cheap-looking shadows

Overly rounded “AI SaaS” designs

Random colourful icons

The website should feel calm, intelligent, structured and premium.

🔤 TYPOGRAPHY

Use large, bold, editorial typography for headlines.

Headlines should feel powerful and spacious.

Example style:

ROTINA PRODUTIVA

Very large text with intentional line breaks:

RITMO
QUE
FUNCIONA

Use clean modern sans-serif typography.

Use generous whitespace throughout the entire website.

✨ IMPORTANT DESIGN RULES

The entire website must look cohesive.

It must look like it was designed by the same designer who created the PDF.

Use the PDF's clean, neutral, editorial aesthetic as the main inspiration.

Do NOT make it look like a generic SaaS website.

Do NOT use excessive cards everywhere.

Avoid colourful gradients.

Avoid bright blue buttons.

Use subtle borders and elegant spacing.

Make typography the main visual element.

Use large section numbers.

Make every section feel intentional.

Add smooth, subtle animations when scrolling.

Make the website fully responsive for mobile.

The final result should feel like a premium interactive digital experience based directly on the “Rotina Produtiva — Ritmo Que Funciona” guide, not just a generic sales page.
